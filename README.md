# ISO 27001:2022 資產管理｜Q 版 Allan Lo 動畫教學簡報

依 ISO/IEC 27001:2022 附錄 A 控制措施屬性「運作能力 Operational capabilities：Asset management 資產管理」，
沿著**資產生命週期**（管理階層 → 組織內 → 內外流動 → 組織外 → 人員異動 → 設備汰除）介紹 17 項控制措施，
分三個面向教學：

1. **ISMS 作業重點**：組織要做什麼
2. **稽核查核重點**：稽核員怎麼查（文件審查、雙向抽樣、現場觀察、人員訪談）
3. **常見的缺失**：現場常開出的缺失

另含 2 個實際案例（離職工程師、報廢事務機硬碟）、2 題小測驗與總整理矩陣。
講師為 Q 版 Allan Lo（台灣男聲 `zh-TW-YunJheNeural`），助教阿拉蕾（`zh-TW-HsiaoYuNeural`）串場，全片約 15 分 24 秒。

| 控制措施 | 名稱 | 生命週期位置 |
|---|---|---|
| 5.37 | 書面化運作程序 | 管理階層 |
| 5.9 | 資訊及其他相關聯資產清冊 | 管理階層 |

## 檔案

| 路徑 | 說明 |
|---|---|
| `index.html` | 互動動畫簡報播放器（有聲、字幕、章節跳轉、全螢幕；空白鍵播放、←→ 換幕） |
| `output/ISO27001_資產管理_AllanLo.mp4` | 輸出影片（1280×720） |
| `講稿.md` | 完整講稿（含時間碼） |
| `build/lesson.py` | **腳本與分鏡**：要改台詞、內容都改這裡 |
| `build/build.py` | 產生旁白 `audio/narration.mp3`、`timeline.js`、`講稿.md` |
| `build/render_video.mjs` | 用 Playwright 逐格渲染並合成 MP4 |

## 使用方式

直接播放：用瀏覽器開 `index.html`（建議透過本機伺服器，例如 `python3 -m http.server`，再開 http://localhost:8000）。

修改內容後重建：

```bash
pip install edge-tts
python3 build/build.py                 # 重新產生語音與時間軸（有快取，只會合成改過的台詞）
node build/render_video.mjs            # 重新輸出 MP4（需 playwright + ffmpeg）
node build/render_video.mjs --stills 10,200   # 只輸出指定秒數截圖檢查版面
```

> 角色皆為以 SVG 繪製的原創 Q 版造型。「阿拉蕾」為知名漫畫角色名稱，若課程對外商業販售，建議改用自有吉祥物名稱與造型。
